# 🦀 Clawd: питомец на панели задач

Маленький пиксельный краб Clawd живёт прямо на панели задач Windows: гуляет по ней, моргает, радуется, просит токены, а ночью ложится спать.

*A tiny pixel crab that lives on your Windows taskbar. Unofficial fan project.*

> **v0.2.0 «Open Labs»: открытый бета-тест.** Следующая версия будет финальной.

## Что умеет

- Гуляет по панели задач, моргает, радуется, обижается, если его слишком часто тыкать
- **Голод:** раз в ~20 минут просит токены. Клик по голодному крабу: прибегают человечки и строят мини-дата-центр
- **Сон:** в 22:00 по времени ПК его укладывают в кровать, в 8:00 он просыпается и пьёт кофе
- **Имя:** ПКМ по крабу → «Дать имя…»
- При самом первом запуске вылезает из коробки
- В декабре в углу панели появляются коробки с талисманами
- **Панель параметров** слева на панели задач (клик по вкладке с крабом): сытость, общение, привязанность, АФК и ревность
- Слушает музыку вместе с вами: когда что-то играет, надевает наушники
- Ночью просит сделать музыку тише, а если его проигнорировать, обижается, уходит и хлопает дверью
- Его можно **гладить** (водить курсором по нему) и **перетаскивать** (зажать и нести, потом он падает обратно на панель)
- Есть пасхалки 🤫

## Установка

Скачайте `Clawd-Setup-*.exe` на странице [Releases](../../releases) и запустите. Установка не требует прав администратора, .NET ставить не нужно. В установщике можно включить автозапуск вместе с Windows.

Windows может показать предупреждение SmartScreen, так как установщик не подписан: «Подробнее» → «Выполнить в любом случае».

Требования: Windows 10/11 x64.

## Управление

- **ЛКМ** по крабу: потрогать
- **ПКМ**: меню (имя, выход)

## Сборка из исходников

Нужны [.NET 8 SDK](https://dotnet.microsoft.com/download) и (для установщика) [Inno Setup 6+](https://jrsoftware.org/isdl.php).

```powershell
# запустить для разработки
dotnet run --project src/Clawd

# собрать Clawd.exe и установщик в dist/
./build.ps1
```

Релиз на GitHub: создайте тег `v0.2.0-beta` (теги с `beta` публикуются как пре-релиз) и отправьте его в репозиторий. GitHub Actions соберёт установщик и приложит к релизу.

## Linux

Экспериментально: собирается и запускается из исходников, краб ходит по нижнему краю экрана (лучше всего работает на X11, на Wayland возможны ограничения). Некоторые пасхалки привязаны к Windows.
